Configure office hours, late grace period, late-to-LOP rules, and payroll cycle for this account. Attendance late marking and payroll (working days / present days / LOP) use these values.

Office Timings
Official check-in time (e.g. 10:00)
Expected logout time (e.g. 18:30). Leaving earlier marks Early-logout.
Check-in after {{ lateCutoffPreview }} is marked Late.
Late → Loss of Pay (LOP)
Example: if set to 3, then 3 late check-ins + early logouts combined = 1 day LOP deduction.
Professional Tax (by salary)
Min Salary (₹) Professional Tax (₹) Action
Highest matching min salary wins. Default: ≥ ₹20,001 → ₹200 | ≥ ₹15,001 → ₹150 | else ₹0
Payroll Cycle
Full month uses 1st–last day. Custom cycle uses a start day (e.g. 26th of previous month to 25th of salary month).
For day 26: June payroll = 26 May – 25 June. Working days & attendance are counted in this range.
Paid Leave (Payroll)
Default 1. How many paid leave days to credit each eligible payroll month.
Joining month is not counted. After this many months, paid leave starts. Example: join in Jan, set 3 → eligible from May (5th month).
IP Address Restriction
When enabled, users must be on an allowed IP (managed under IP Address menu) to access the system / check-in. Turn OFF to disable IP checks for this account everywhere.
How it works
  • Late check-in if check-in is after start time + grace (currently after {{ lateCutoffPreview }}).
  • Early logout before office end time is marked Early-logout (separate from Late).
  • Payroll LOP = floor((late check-ins + early logouts) ÷ {{ officePayrollForm.get("latesPerLop")?.value || 3 }}).
  • Paid leave = {{ officePayrollForm.get("casualLeavesPerMonth")?.value || 1 }} day(s) / month. Joining month not counted; eligible after {{ officePayrollForm.get("casualLeaveAfterMonths")?.value || 3 }} month(s) (e.g. join Jan + 3 → from May).
  • Working days / present days follow the selected payroll cycle (Sundays & holidays excluded from working days).
  • IP restriction is {{ officePayrollForm.get("ipRestrictionEnabled")?.value ? "ENABLED" : "DISABLED" }} for this account.
